# Курс по РИП
Репозиторий содержит реализацию клиент-серверного приложения для управления заявками на умные устройства.  
Проект включает:  
- Бэкенд на **Go** (Gin/GORM) с REST API, авторизацией, MinIO и Redis  
- SPA на **React + TypeScript** с маршрутизацией и компонентами Bootstrap
- Итоговый бэкенд приложения (методы для взаимодействия с внешним асинхронным микросервисом)
